# Agar-Smart

A smart monitoring and automation workspace for Solar Agarbatti Production System, 3D visualization, and AI applications.

## Projects in this Repository

- **`solar_agarbatti_system/`**: Complete Solar Agarbatti Machine System
  - `flutter_app/`: Cross-platform mobile control application
  - `backend/`: Node.js backend server API
  - `web_dashboard/`: Web monitoring dashboard
  - `esp32_firmware/`: IoT micro-controller firmware
- **`bhumi-3d/`**: 3D visualization frontend and services
- **`SafePath AI/`**: SafePath AI project module

## Getting Started

Refer to individual project directories for setup and running instructions.
